# Etapa 3 — Salvar estudos em Anotações

Objetivo: permitir que um estudo gerado na `StudyScreen` seja salvo em Anotações com referência, pergunta e resposta.

Critérios de aceite:
- O botão só aparece quando existe resposta.
- O estudo é salvo usando a mesma persistência de anotações da aplicação ativa.
- O registro contém referência, consulta e resposta.
- O botão evita duplicação imediata após salvar.
- Type check, lint e build devem passar.
